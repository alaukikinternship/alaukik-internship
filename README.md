## 📚 Learning Journey

## Phase 1 — Java Fundamentals (Days 1–5)

This phase focuses on understanding Java syntax, program execution, basic programming logic, and problem-solving.

### Day 1 — Java Introduction & Development Environment

**What I Learned**

- **Java:** Understood Java as an object-oriented, platform-independent programming language used for developing desktop, web, and enterprise applications.
- **JDK, JRE, and JVM:** Learned how the JDK provides development tools, the JRE provides the runtime environment, and the JVM executes Java bytecode.
- **Java Architecture:** Explored how Java source code is compiled into bytecode and executed by the JVM.
- **Compilation and Execution:** Practiced using `javac` to compile Java files and `java` to execute compiled programs.
- **Development Environment:** Configured the JDK and IDE for Java development.

**Practical Implementation**

- `HelloJava.java` — Created and executed my first Java program using the `main()` method and `System.out.println()`.

**Learning Outcome:** Understood the complete Java execution process, from writing source code to running a program.

### Day 2 — Variables, Data Types & Operators

**What I Learned**

- **Variables:** Learned how to store and access data using named memory locations.
- **Primitive Data Types:** Explored `int`, `float`, `double`, `char`, `boolean`, and other primitive types.
- **Reference Types:** Understood how variables can refer to objects and arrays.
- **Type Casting:** Practiced converting values between compatible data types.
- **Operators:** Used arithmetic, relational, logical, assignment, unary, ternary, and bitwise operators to perform different operations.

**Practical Implementation**

- `StudentMarksCalculator.java` — Developed a program to calculate total marks, percentage, and grades based on student marks.
- **PDF Assignment:** Simple Electricity Bill Calculator.

**Learning Outcome:** Developed an understanding of Java data storage, type conversion, and expressions.

### Day 3 — Conditional Statements

**What I Learned**

- **if and if-else:** Used conditions to control program execution.
- **Nested Conditions:** Implemented conditions inside other conditions.
- **else-if Ladder:** Evaluated multiple conditions in sequence.
- **switch:** Used switch statements to select operations based on specific values.
- **Logical Conditions:** Combined multiple conditions using logical operators.

**Practical Implementation**

- `StudentGradeManagementSystem.java` — Created a student result system that evaluates marks and calculates results using conditional statements.

**Learning Outcome:** Learned how to implement decision-making logic in Java applications.

### Day 4 — Loops & Patterns

**What I Learned**

- **for Loop:** Repeated operations for a known number of iterations.
- **while Loop:** Executed statements while a condition remained true.
- **do-while Loop:** Ensured that a block executes at least once.
- **Nested Loops:** Used loops inside loops to generate patterns.
- **break and continue:** Controlled loop execution and skipped selected iterations.

**Programs Practiced**

- `pattern.java` — Generated star and number patterns using nested loops.
- `CheckPrimeNumber.java` — Checked whether a number is prime.
- `FibonacciSeries.java` — Generated Fibonacci numbers.
- `Factorial.java` — Calculated factorial using loops.
- `Palindrome.java` — Checked whether a number reads the same forward and backward.
- `ReverseNumber.java` — Reversed the digits of a number.

**Assignments:** Armstrong Number, Prime Number Checker, Fibonacci Series, Factorial, Palindrome, and Reverse Number.

**Learning Outcome:** Improved logical thinking and learned to solve mathematical problems using iterative programming.

### Day 5 — Methods & Arrays

**What I Learned**

- **Methods:** Learned to divide a program into reusable blocks of code.
- **Parameters and Return Values:** Passed data to methods and returned calculated results.
- **Method Overloading:** Implemented multiple methods with the same name but different parameter lists.
- **Variables Scope:** Understood local and class-level variables.
- **One-Dimensional Arrays:** Stored multiple values of the same type in a single array.
- **Two-Dimensional Arrays:** Organized data in rows and columns.

**Programs Practiced**

- `StudentResultManagement.java` — Managed student names, marks, and results.
- `MaximumNumber.java` — Found the largest element in an array.
- `MinimumNumber.java` — Found the smallest element in an array.
- `Average.java` — Calculated the average of array elements.
- `Sorting.java` — Arranged array elements in sorted order.
- `Searching.java` — Searched for a specific element in an array.

**Learning Outcome:** Learned code reusability through methods and data management using arrays.

## Phase 2 — Object-Oriented Programming (Days 6–10)

This phase focuses on writing structured, reusable, and maintainable Java programs using Object-Oriented Programming principles.

### Day 6 — Classes & Objects

**What I Learned**

- **Class:** Understood a class as a blueprint that defines the properties and behaviours of objects.
- **Object:** Learned how to create instances of classes to represent real-world entities.
- **Fields and Methods:** Defined object properties and behaviours.
- **Constructors:** Used constructors to initialize objects during their creation.
- **this Keyword:** Used `this` to refer to the current object.
- **Static vs Instance Members:** Understood the difference between class-level and object-level members.

**Practical Implementation**

- Created an Employee class containing employee ID, name, salary, and department.
- Implemented a `displayDetails()` method to display employee information.

**Assignment:** Bank Account Management System.

**Learning Outcome:** Understood how real-world entities can be represented using Java classes and objects.

### Day 7 — Encapsulation

**What I Learned**

- **Encapsulation:** Learned to combine data and related methods inside a class.
- **Access Modifiers:** Studied `private`, `public`, `protected`, and default access.
- **Getters and Setters:** Controlled access to private fields.
- **Data Hiding:** Protected object data from direct external modification.
- **Validation:** Applied conditions before updating important values.

**Practical Implementation**

- Created a BankAccount class with private account details.
- Implemented deposit, withdrawal, balance checking, and transaction validation.

**Assignment:** Developed a secure Employee class using encapsulation.

**Learning Outcome:** Learned how to protect application data and control access to object properties.

### Day 8 — Inheritance

**What I Learned**

- **Inheritance:** Understood how one class can reuse properties and methods from another class.
- **extends Keyword:** Established parent-child relationships between classes.
- **Types of Inheritance:** Studied single, multilevel, and hierarchical inheritance, along with multiple inheritance limitations in Java classes.
- **Method Overriding:** Customized inherited methods in child classes.
- **super Keyword:** Accessed parent-class members and constructors.
- **Constructor Chaining:** Understood constructor execution across inheritance hierarchies.

**Practical Implementation**

- Designed an Employee → Developer → SeniorDeveloper class hierarchy.

**Assignment:** Vehicle Management System with Car, Bike, and Truck classes.

**Learning Outcome:** Learned code reuse and class relationships through inheritance.

### Day 9 — Polymorphism

**What I Learned**

- **Polymorphism:** Understood how one interface or parent reference can represent different object behaviours.
- **Compile-Time Polymorphism:** Implemented method overloading.
- **Runtime Polymorphism:** Implemented method overriding.
- **Upcasting and Downcasting:** Converted references between parent and child types.
- **Dynamic Method Dispatch:** Understood how Java selects overridden methods at runtime.

**Practical Implementation**

- Designed a Payment system with CashPayment, CardPayment, and UPIPayment implementations.

**Assignment:** Basic Payment Processing System.

**Learning Outcome:** Learned how polymorphism makes applications flexible and extensible.

### Day 10 — Abstraction & Interfaces

**What I Learned**

- **Abstraction:** Learned to expose essential functionality while hiding implementation details.
- **Abstract Classes:** Created classes containing abstract and concrete methods.
- **Interfaces:** Defined contracts that implementing classes must follow.
- **Multiple Interfaces:** Used interfaces to support multiple behavioural contracts.
- **Default and Static Methods:** Explored additional methods supported by Java interfaces.
- **Interface vs Abstract Class:** Compared their purpose and usage.

**Practical Implementation**

- Designed a PaymentService structure supporting UPI, Card, and Net Banking payments.

**Assignment:** Notification System supporting Email, SMS, and WhatsApp.

**Learning Outcome:** Understood how abstraction and interfaces help create loosely coupled application designs.

This phase focuses on modern Java programming features, functional-style operations, date-time handling, and concurrent execution.

### Day 16 — Generics

**What I Learned**

- **Generics:** Learned to write reusable classes and methods that work with different data types.
- **Generic Classes:** Created classes with type parameters.
- **Generic Methods:** Implemented methods that accept generic types.
- **Type Safety:** Reduced unnecessary type casting and helped detect type errors at compile time.

### Day 17 — Functional Programming

**What I Learned**

- **Functional Interfaces:** Studied interfaces containing one abstract method.
- **Lambda Expressions:** Wrote concise implementations of functional interfaces.
- **Predicate:** Used conditions to test input values.
- **Consumer:** Performed operations on supplied data without returning a result.
- **Supplier:** Created values without accepting input.

### Day 18 — Stream API

**What I Learned**

- **Stream API:** Processed collections using declarative data-processing operations.
- **filter():** Selected elements based on conditions.
- **map():** Transformed elements into another form.
- **sorted():** Arranged elements in a specified order.
- **collect():** Collected processed results into collections.
- **reduce():** Combined stream elements into a single result.
- **forEach():** Performed an action on each element.
- **distinct():** Removed duplicate elements.
- **limit():** Restricted the number of processed elements.

**Practical Implementation**

- Built an Employee Analytics System using Stream API.

**Features**

- Group employees by department.
- Find the highest salary.

**Learning Outcome:** Learned how to process and analyze collection data using Stream API operations.

- **LocalDate:** Worked with dates without time information.

- **LocalDateTime:** Managed combined date and time values.
- **Date Formatting:** Converted date-time values into readable formats.
- **Java Time API:** Used the modern `java.time` package for date and time calculations.

**What I Learned**

- **Thread Lifecycle:** Explored thread states and transitions during execution.
- **Creating Threads:** Learned to create and start independent threads using the Thread class.
- **Runnable Interface:** Separated the task's implementation from the thread that executes it.
- **Thread Synchronization:** Understood how synchronized access helps protect shared resources.
- **Race Condition:** Learned how concurrent access to shared data can produce unexpected results.
- **ExecutorService:** Studied a higher-level API for managing asynchronous task execution.
- **Thread Pool:** Understood how a group of reusable worker threads can process multiple tasks.

**Technologies Used**

## ▶️ How to Compile and Run

Java programs can be compiled and executed using the JDK command-line tools.

**1. Verify Java Installation**

```bash
java -version
javac -version
```

**2. Navigate to a Program Directory**

```bash
cd day-4
```

**3. Compile the Java Source File**

```bash
javac CheckPrimeNumber.java
```

**4. Execute the Compiled Program**

```bash
java CheckPrimeNumber
```

Replace the filename and class name according to the program you want to execute.
