## ▶️ How to Compile and Run

Make sure Java is installed and configured on your system.

Check the Java installation:

```bash
java -version
javac -version
```

Navigate to the required folder. For example:

```bash
cd day-4
```

Compile a Java program:

```bash
javac CheckPrimeNumber.java
```

Run the program:

```bash
java CheckPrimeNumber
```

Replace the filename and class name with the program you want to execute.
